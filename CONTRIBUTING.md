# Contributing

## Team Rules

1. Never push directly to `main`.
2. Each member works on their assigned feature branch.
3. Use Pull Requests to merge into `main`.
4. Do not modify another member's module without discussion.
5. Follow the interfaces defined in `docs/interfaces.md`.
6. Add tests for new functionality.
7. Never commit API keys or `.env` files.
8. Do not commit large datasets or model checkpoints.
